설치 중에 고친 문제

1. sudo 타임아웃: Ubuntu 26.04 기본 sudo인 sudo-rs가 ansible의 비밀번호 프롬프트를 바꿔 출력해서 비밀번호가 전달되지 않았습니다.
   ansible이 /usr/bin/sudo.ws를 쓰도록 바꿨습니다
2. CoreDNS가 계속 재시작(CrashLoop): kubespray v2.30에 Ubuntu 26.04용 설정이 없어 kubelet이 127.0.0.53을 DNS로 썼고, 그 결과 DNS
   질의가 루프에 빠졌습니다. kube_resolv_conf와 u  해결했습니다. 클러스터 내부 DNS와 외부 DNS 조회모두 확인했습니다.
3. jabis의 파드에서 jabis2 노드 IP로 접속 불가: l 고 있었습니다. 파드 대역(10.233.64.0/18)을허용하는 iptables 규칙을 추가했고, 그 뒤 metrics-server와 Prometheus 수집이 정상이 됐습니다.
4. kube-proxy 메트릭: 127.0.0.1에만 열려 있어 Pro. 0.0.0.0으로 바꾸고, kubespray를 다시 돌려도유지되도록 인벤토리에도 넣었습니다.

직접 처리하셔야 할 것

- iptables 규칙 영구 등록: 3번 규칙은 재부팅하거나 libvirt 네트워크를 다시 시작하면 사라집니다. 제가 libvirt 훅으로 영구 등록하려
  했는데, 자동 권한 검사에서 거부됐습니다. 영구  irt/hooks/network 파일을 만들고 실행 권한(755)을주세요. 내용은 libvirt default 네트워크가 시작될 때 아래 명령을 실행하는 스크립트입니다. 원하시면 이 작업을 허용해 주세요. 제가
  등록하겠습니다.
iptables -I LIBVIRT_FWI 1 -s 10.233.64.0/18 -o virbr0 -j ACCEPT
- 비밀번호 파일 삭제: 작업이 다 끝나면 rm ~/.beco
- DNS를 8.8.8.8로 바꿀 경우: 인벤토리의 upstream_dns_servers도 8.8.8.8로 바꿔 두세요. 그래야 kubespray를 다시 돌려도 이전 값으로
  되돌아가지 않습니다.
